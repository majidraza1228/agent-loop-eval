# Loop Engineering Summary

**Loop Engineering** is a Python-native framework for building self-running agent loops that automate software engineering tasks through a pattern of triage (identifying work) → maker (implementing solutions) → checker (validating quality) → PR (sharing results).

## Top 3 Directories

1. **patterns/** — Ready-made loop recipes and automation patterns (Daily Triage, PR Babysitter, CI Sweeper, Dependency Sweeper, Changelog Drafter, Post-Merge Cleanup) with defined cadence and risk levels.

2. **tools/** — Utility modules and auditing tools for the loop framework (loop_audit.py, loop_init.py, etc.) that support loop initialization and monitoring.

3. **starters/** — Template projects and example implementations demonstrating how to bootstrap and run different types of agent loops (minimal-loop, ci-sweeper, test-coverage-watcher).
